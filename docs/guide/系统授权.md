# 系统授权

系统授权为长期授权，一个激活码绑定一个系统安装。它与管理员登录密码、Telegram 凭据和 CloakBrowser Key 无关，不要填到其他设置中。

## 未授权可以使用什么

未授权时，可配置并启用以下内置插件：

- 小姐姐视频
- 举牌
- P站图片
- Webhook 通知桥
- 插件开发探针

这些插件不需要先从商店下载。需要 Telegram 的插件，仍要先填写 Telegram 凭据，并按要求添加账号或 Bot；没有配置时，部分插件可能暂不显示。

插件市场、添加仓库、上传插件和其他插件的运行需要系统授权。即使手动把其他插件放入插件目录，未授权时也不会显示或运行。

## 更新前先准备

如果现有系统正在使用其他插件，更新前请先备份 `data`、`sessions`、`plugins`，并准备激活码。未授权时，其他插件会停止运行，但不会删除它们的文件、设置和数据。完成授权后，再检查插件状态和日志。

备份和更新步骤见[更新、备份与维护](Maintenance.md)。不要清空数据目录或重复重装来处理授权问题。

## 填写激活码

1. 使用管理员账号登录网页。
2. 打开“系统设置 → 账号与凭据”，滚动到底部的“系统授权”。也可用“搜索设置”查找“系统授权”。
3. 页面显示当前状态和安装标识。安装标识由系统生成，不需要手动修改。
4. 在“激活码”中填写完整的授权码，点击“授权”。
5. 确认状态变为“已授权”，再打开插件市场或检查已有插件。电脑侧栏的版本号旁会显示 Pro 标识；未授权时不显示。

首次绑定和后续验证都需要系统能访问授权服务。长期授权没有按天数或日期到期的限制，但不等于可以永久离线；长时间无法联网验证时，会暂时回到内置插件范围。恢复网络并验证成功后可继续使用，设置和数据会保留。

不要把激活码、完整配置文件或授权凭证发到群里、公开 Issue 或截图中。

## 授权成功后，插件还没同步

系统会尝试把内置插件接入官方仓库的对应版本，保留已有配置；不会把所有新安装插件自动开启。授权状态与插件下载结果是两回事。

如果显示“部分插件同步失败”：

1. 先看“运行日志”，确认服务器能访问 GitHub，代理是否正常。
2. 遇到 GitHub 限流时，稍后重试；也可在“系统设置 → 运行环境 → 运行代理”填写自己的 GitHub Token，保存后重试。
3. 回到“系统授权”，点击“重试同步”，等待结果。不要反复点击授权或更换激活码来催下载。

GitHub Token 用于访问 GitHub，与激活码不同。只使用自己的 Token，不要公开，也不要把它填入激活码输入框。

## 更换、解除和保留授权

- **更换激活码：** 在“系统授权”点击“更换激活码”，填写新的有效码并授权。
- **解除授权：** 点击“解除授权”并确认。解除后只能使用内置插件，其他插件会停止运行，已有设置和数据保留。
- **更新镜像或重建容器：** 保留原 `data` 挂载，安装标识和授权状态会随数据保留，不需要为普通重启重新授权。
- **更换服务器：** 先做好完整备份并停止旧实例，再按迁移步骤操作；不要让两个实例共用同一套授权和 Telegram 会话。需要将授权转给另一套独立安装时，先解除原安装的授权。

## 常见提示

| 提示或现象 | 怎么处理 |
| --- | --- |
| 未授权 | 只用内置插件可继续使用；需要更多插件时填写有效激活码 |
| 激活码已绑定其他系统 | 核对是否用了另一套安装；先解除原安装授权，不要删除当前数据目录 |
| 暂时无法连接授权服务 | 检查服务器网络，稍后重试；不要把系统管理页面地址填成授权服务地址 |
| 已授权，但官方插件同步失败 | 检查 GitHub 网络、限流和 Token，再点击“重试同步” |
| 授权已撤销 | 原激活码不能继续使用，请联系提供授权的管理员 |
| 重建容器后安装标识改变 | 先检查是否挂载了原 `data` 目录，不要直接覆盖或删除数据 |
